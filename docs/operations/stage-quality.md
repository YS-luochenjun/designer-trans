# 逐阶段质量

只有质量凭证与当前底片 SHA 一致的无字底片才解锁译字。
`complete_candidate`、诊断草稿和技术导出成功均保持这一要求。
轻微正常观看纹理可以接受并披露，可读原文、双语叠字、主体损伤、
漏范围和必需音轨缺失不能放行。

1. 原片分析登记文字实例、实际帧边界、样式、运动和遮挡。
2. 清底 Work 观察、制作并复核改区与未改区，登记候选、接受或拒绝及实际费用。
3. 清底复核覆盖全部文字实例，核当前底片、剩余范围与实际证据。
4. 译字核语义、样式、运动、显隐和遮挡；合成核画面、音轨与时钟完整性。
5. 完整候选供人工完整视听批准，批准绑定实际视频 SHA，再允许交付。

模型抽帧审核、可播放文件、补片清单与局部接受均不代表人工完整验收。
本地工具只能产生候选或诊断；程序校验像素、帧覆盖、依赖与音频完整性，
真实视觉质量另行审查。

评分用于比较有实际观察依据的候选，不是自动识字或客观视觉真值。
达到80分且无硬伤即可接受并披露轻微纹理；高分不能抵消漏范围或可读原文。
单个方法失败后先由 Route 评估替代方法及其他可做范围，不据此停止整个任务。

普通失败、模型审核修正和人工不通过进入 [Route 协调](../architecture/route-work.md)，
在原额度内安排返工。已有用户暂停保持；未知外部结果先核原请求，不重复派发。
成功的本地导出恢复消费一次意图，只证明输出完整性，不豁免清底质量。

明确清空旧阶段使用公开阶段重置接口，绑定新鲜版本、暂停和验证备份，
保留原片、独立音频、累计调用与未结核账证据。预算见[资源预算](resource-budget.md)。
