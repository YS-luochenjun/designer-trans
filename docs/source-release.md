# 项目源码发布

公开发布使用明确的文件白名单，与本机运行目录分开。仓库只携带项目实现及运行所需的公开资源。

## 包含与排除

包含后端、前端源码与锁文件、数据合同、工作流、提示与知识资源、公开配置模板、必要安装和桥接工具，以及整理后的项目文档。

排除生产媒体、任务数据库、补片、候选、预览、日志、费用明细、登录状态、凭据、本机配置、模型权重、依赖安装目录、构建输出、测试源码及结果、本地事故文档、截图、历史 Git 记录。

本机完整开发项目和测试无需删除。公开副本不是第二套生产服务。

## 导出与核验

从维护者的完整开发项目运行，目标必须是尚不存在的独立目录，可位于项目之外，或明确排除的 `runtime/releases/` 下：

```powershell
python scripts/export_public_source.py export --destination D:\Releases\designer-trans-source
python scripts/export_public_source.py verify --destination D:\Releases\designer-trans-source
```

脚本拒绝覆盖现有目录，逐文件核对 SHA，检查高置信度凭据模式，拒绝选中源文件中的链接与异常类型。`SOURCE-MANIFEST.json` 记录实际导出内容，核验会拒绝缺失、修改或额外文件。自动检查不能替代维护者对公开范围与版权的审阅。

整理后的 README 和文档来自完整项目的 `docs/public/`，因此不会把本机制作记录和旧截图一起带入。公开副本也可再次运行同一导出脚本。

导出不执行 Git、push、服务重启、任务恢复或模型调用。维护者检查清单后，再对该副本建立提交并推送到用户指定的仓库；必须核对远端目标及推送后的提交身份。
