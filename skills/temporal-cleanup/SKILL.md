# 连续帧清字

## 先判断当前能力

以本轮 available_tools 为准。track 是 CPU 初始模板位置/小幅缩放跟踪，输出未经审核的轨迹；tracked_donor 使用已观察轨迹逐帧变换同源干净补片，支持显式前景保护。它们不是语义分割、光流补全、透视恢复或 ProPainter。

VSR、ProPainter、RunComfy 原文放在 references 中供工程接入参考，不作为生产指令自动执行；本项目没有因为保存 skill 就安装这些工具。RunComfy 是额外收费渠道。ProPainter 商业使用需核对许可。

## 执行顺序

1. 锁定原片、底片和帧时钟，读取 work_queue 与全部未覆盖区间。完成条件：每个目标文字有身份、显隐范围、所在镜头和保护对象，不混用请求时间与实际帧时间。
2. 看原片首次出现、退出和转场，区分移动、缩放、遮挡、静止。需要定位时，track 只运行一个已观察镜头的短范围。完成条件：检查轨迹首尾、最大位移/缩放与置信度下降处；lost 后未跟到的帧仍是缺口。高相关不代表跟对对象。
3. 选择方法：简单均匀面用 flat；干净边缘低纹理面可用 local_surface；同镜头有干净供体且运动可描述时用 tracked_donor。其区域关键帧须覆盖编辑起止，含少量干净边缘用于逐帧接缝检查。完成条件：供体不含待去文字且背景、曝光、保护区匹配；复杂旋转、透视、不可见背景不冒充已解决。
4. 先短样再扩展。候选保留输入哈希和方法证据。失败分类：漏选、轨迹丢失、遮挡错误、供体不匹配、修复结构损伤、时间边界错位。完成条件：新尝试明确改变哪个有证据的问题；相同失败参数不重跑。
5. 按 media-review 三方对照及 clean-quality 评分，检查连续性、残字、保护对象和首尾内外帧。轻微纹理/发丝差异可记录，可读残字和明显闪烁不通过。完成条件：真实画面符合评分才 accept；工具成功与区间账本不替代质量检查。
6. 全部区间覆盖后独立复核当前底片，finish 提供 review_sha256、reviewed_source_ids、quality 和 evidence。完成条件：哈希等于当前底片且全部文字ID逐项检查；抽帧审核不能声称已播放全片。存在残字保留工作版，不进入译字。

## 译文运动

运动资料来自原片，清底包络不能代替排版区域。unknown 不当 static，动态文字需要实际轨迹和证据。跟踪报告先复核再用于源设计；不要把未验证结果自动当成通过。语义、字体适配、描边、颜色、换行和显隐分别检查。
